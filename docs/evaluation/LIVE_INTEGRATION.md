# Live integration evidence

Checked 23 October 2026. These are integration and computational observations, not an independent human preference study.

## Bounded feasibility cases

The two predeclared illustrative pairings were Radiohead + The Grand Budapest Hotel, and Beyoncé + Spirited Away. In New York, each admitted shortlist had ten identities returned under both reference-conditioned ranking requests. The orders differed across cultural lenses. Repeating the first case's artist-conditioned request produced the identical order. The first direct combined-signal baseline was also retrieved. Fifteen provider requests were used across these two initial probes.

This establishes usable common coverage and a nondegenerate cultural basis in those cases. It does not establish subjective usefulness, unique invention, general geographic coverage, or superiority over direct Qloo ranking. The redundant-basis control is an authored engine test that produces no manufactured question; it is not represented as an additional live provider request.

## Actual MCP client and backend

A real MCP stdio client listed and invoked `parallax_advise` against both the local backend and the deployed public HTTPS backend. Each run resolved the two typed identities, prepared ten live Qloo places, obtained a comparison, submitted one explicit A response, removed that response by sending the retained empty answer list, and verified exact agreement with the initial decision. Deleting the temporary evidence handle caused the subsequent remote advise request to be rejected.

This was a protocol-client invocation. No LLM inference or autonomous language-model invocation is claimed.

## Shared-store concurrency

Twelve simultaneous reservations hit the actual dedicated Postgres quota function under a cap of three. Exactly three were admitted. A denied multi-dimension reservation did not create or increment its otherwise eligible second counter. Verification counters were removed afterwards. This exercises shared database atomicity, not an in-memory mock.

## Unit and HTTP evidence

The engine oracle enumerates action losses and answer branches independently. Tests cover the two- and three-dimensional simplex, all candidate pairs, removal/rebuild, nonrelative responses, vetoes, stopping, missing ranks, malformed provider responses, safe URLs, and quota denial. An actual local HTTP server with an explicitly doubled provider/store checks signed sessions, evidence scope, bounds, deletion, and structured errors. HTTP doubles are not counted as live Qloo evidence.
