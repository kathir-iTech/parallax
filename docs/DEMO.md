# Try PARALLAX

Open [the hosted studio](https://parallax-culture.vercel.app) in a new private browser window. No login, purchase or personal API key is needed. This walkthrough uses the real backend and its finite event allowance.

1. Click **Radiohead × Grand Budapest** beneath the reference fields. Wait for **Example identities selected**. These are confirmed artist and movie identities, not unconfirmed search text.
2. Click **Find my places** once. Wait for discovery to finish. The page then shows comparisons, a three-place shortlist, and **Live Qloo observations**. A service error is an error; do not interpret it as a successful retrieval.
3. Read the two place cards. Click the place you would rather try. Inspect the shortlist and **What changed?**. A particular place is not guaranteed to lead; ordering follows current provider observations and explicit choices.
4. Click **1 choice** beside the history icon near the top-right. In the dialog, click the trash-can control beside **COMPARISON 1** (accessible label **Remove comparison 1**). The model is rebuilt from retained choices. Close with Escape. Both, neither and skip have their own semantics; they are not alternate spellings of A or B.
5. Click **See my places** when a comparison is displayed. Inspect the selected place and its photograph, source credit, address, directions and venue link.
6. Click **Explore on map**. In the details panel, open **All 10 places** if collapsed and choose another named candidate. Drag or zoom the map. Numbered markers offer another selection method; nearby places can overlap until zoomed in. **Connections** shows the separate cultural-association plot. Return with **Back to your places**.
7. Open **Why these places?** for the actual reference-conditioned ranks, provider baseline, model assumptions and evidence age. Model scores are not calibrated enjoyment probabilities.
8. Optionally use **Save on this device** or **Field notes**. Reloaded observations are labeled restored; they are not a new provider request. **How it works & privacy → Remove app data** removes local state and reachable temporary evidence.

## Try the agent path

After `npm ci`, run `npm run demo:agent`. It launches an actual MCP stdio client against the same public backend, applies a declared scripted sample answer, checks answer removal, and forgets temporary evidence. It requires no judge-supplied Qloo key and invokes no LLM. See [the connection guide](AGENT.md).

## Useful boundaries

The first edition supports a bounded New York area and choosing one place. It does not book venues or certify current visiting conditions. Public-service and event allowances can limit new retrievals. Existing local decisions can still be inspected when new retrievals are unavailable. Photos illustrate verified locations; historical appearances and explicit missing-photo placeholders are identified.
